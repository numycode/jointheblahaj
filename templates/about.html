about this site!

hi! this site was inspired off of Slack Gold by milkcool, which set your status with a link too.
this made it spread decently far across the (Hack Club) Slack (since people saw the status, clicked the link, and left the status as it, causing many others to do the same),
and many well-known users used the status. i'm trying to recreate that with blahåj, the IKEA shark that is loved throughout Hack Club.

unlike milkcool's app (which uses TypeScript), i'm using Flask, and also Tailwind CSS, which are both firsts for me. Flask handles the slack API stuff, and serves the pages.
it is running in a Docker container on theMAINFRAME, my mini PC, and has decent (ish) uptime.
